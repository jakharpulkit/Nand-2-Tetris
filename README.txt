Nand2Tetris Combined HDL Projects
=================================

Project 1: Boolean logic chips
Project 2: Arithmetic chips
Project 3: Sequential chips and RAM hierarchy

Each project has its own folder. Keep the .hdl files together within their project
folder and test using the official Nand2Tetris Hardware Simulator test scripts.

IMPORTANT:
- These are starter HDL implementations, not a guarantee of passing every official test.
- Verify all chips with the official .tst scripts and your course's supplied chip files.
- Built-in primitive chips such as Nand and DFF are provided by the simulator.
